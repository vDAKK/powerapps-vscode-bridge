Power Apps X VS Code is installed

One more step in VS Code and you’re all set.

This extension connects the Power Apps Studio formula bar to VS Code. It needs its companion extension Power Apps X VS Code for VS Code, installed on the same computer.

  1. Install the VS Code extension

    From VS Code (Extensions view, search for “Power Apps X VS Code”) or from the Marketplace.

    Open in VS Code View on the Marketplace

  2. Open your app in Power Apps Studio

    A canvas app open for editing, with the Tree view pane visible.

    Open Power Apps

  3. Accept the permission prompt in VS Code

    On first connection, VS Code asks whether it can trust this browser: answer Allow. Then select a control in Studio: its formula opens in VS Code.

The connection status is visible at any time in the extension’s menu (its icon in the toolbar). Everything stays on your computer: the extension only talks to VS Code, on 127.0.0.1. · Help
