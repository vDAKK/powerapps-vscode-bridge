Power Apps X VS Code est installé

Encore une étape côté VS Code, et c’est prêt.

Cette extension relie la barre de formule de Power Apps Studio à VS Code. Elle a besoin de sa jumelle, l’extension Power Apps X VS Code pour VS Code, installée sur le même ordinateur.

  1. Installe l’extension VS Code

    Depuis VS Code (vue Extensions, recherche « Power Apps X VS Code ») ou depuis le Marketplace.

    Ouvrir dans VS Code Voir sur le Marketplace

  2. Ouvre ton app dans Power Apps Studio

    Une canvas app en modification, avec le panneau Arborescence visible.

    Ouvrir Power Apps

  3. Accepte l’autorisation dans VS Code

    À la première connexion, VS Code demande s’il peut faire confiance à ce navigateur : réponds Autoriser. Sélectionne ensuite un contrôle dans Studio : sa formule s’ouvre dans VS Code.

L’état de la connexion est visible à tout moment dans le menu de l’extension (icône dans la barre d’outils). Tout reste sur ton ordinateur : l’extension ne communique qu’avec VS Code, sur 127.0.0.1. · Aide
