# Naviguer sans la souris

En haut de chaque formule, le **fil d’Ariane** est cliquable :

```
▭ scrAccueil › ctnPied › ⬭ btnValider · OnSelect ⌄ · Aperçu · 2 références
```

Remonte vers un conteneur, change de propriété, montre le contrôle à l’écran ou liste les formules qui l’utilisent.

| Raccourci | Action |
|---|---|
| `Ctrl+Alt+F` | Rechercher un contrôle |
| `Ctrl+Alt+P` | Changer de propriété du contrôle courant |
| `Ctrl+Alt+G` | Aller à une formule : tape `Contrôle.Propriété` |
| `Ctrl+Alt+Maj+F` | Rechercher dans toutes les formules |
| `Ctrl+clic` sur `galProjets` | Sélectionner ce contrôle dans Studio |
| `Ctrl+clic` sur `txtNom.Default` | Ouvrir cette formule |
| `Maj+Alt+F` | Mettre en forme la formule |

L’autocomplétion propose les fonctions Power Fx, les noms de contrôles et, après `Contrôle.`, ses propriétés.
